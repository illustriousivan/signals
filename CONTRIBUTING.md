# Contributing

This is a personal study case — the primary goal is self-directed learning, not
open-source collaboration. That said, issues and PRs are welcome if you find them
useful.

## How to Help

1. Open an issue describing what you'd like to explore or improve
2. Fork this repo and submit a PR with your changes
3. Reference the issue number in your commit message (`fixes #N`)

## Learning Focus

This project is meant to be explored, not just consumed. If you're interested in
the Rust side of things:

- Look at how `Callable` uses `Rc` for shared ownership and pointer-based equality
- Check the test suite for usage examples
- Read the ROADMAP.md for what's been learned so far
